# 交通費請款單（App 749）表單體驗改善計畫

> 狀態：**規劃中，尚未改程式**（2026-10-22）。拍板後的決定搬回 [`749_現況與待決事項.md`](749_現況與待決事項.md) §2。

## 1. 問題：明細表格太長

子表格「交通費請款單」有 11 欄：

| 誰在用 | 欄位 |
|---|---|
| 填單的同仁 | 憑證日期、交通工具、拜訪客戶、起訖點、金額、費用歸屬、憑證種類、發票號碼 |
| 會計（或程式自動帶） | 賣方統編、格式、稅額 |

一般螢幕要左右捲動才看得完；同仁要填的 9 欄和會計的 3 欄混在一起，很容易漏填或填錯欄。

### 1.1 做法比較

| 方案 | 做法 | 優點 | 缺點／風險 |
|---|---|---|---|
| A. 拆成兩個子表格 | 「同仁填寫」「會計使用」兩張表 | 原生、穩定 | 兩張表的列要對齊，刪列、排序容易錯位；SAP 轉檔、PDF、發票號碼記錄都要改。**不採用（照指示原生表格不拆）** |
| B. 隱藏會計欄（CSS） | 依標題文字找到欄位索引，對非會計人員用 CSS 把 3 欄藏起來 | 改動最小、表格立刻變短 | kintone 改版 DOM class 可能失效；`setFieldShown` 不支援子表格內的欄位，只能靠 CSS |
| **C. 卡片式填寫（建議）** | 原生表格不拆、照樣存值；新增／編輯畫面另外在空白欄位畫一組「明細卡片」給同仁填，卡片改了就用 `kintone.app.record.set()` 寫回原生表格。會計與詳細頁、列印照樣看原生表格 | 同仁只看到要填的欄位，一列一張卡、字可以放大；存檔、驗證、SAP、PDF 都不用改 | 工作量最大；`set()` 不會觸發 change 事件 → 卡片要自己呼叫 `PR_TRAFFIC_RULES.applyRecordRules`（本次已拆成可共用的函式）；行動版要另外處理（`kintone.mobile.*`） |

### 1.2 建議：B 先上、C 分階段

1. **階段 0（小）**：方案 B——非會計人員隱藏賣方統編、格式、稅額 3 欄（這 3 欄現在都由程式算好或鎖住）；表頭固定、欄寬依內容。
2. **階段 1（中）**：卡片「新增明細」視窗——按鈕跳出 SweetAlert 表單（大字、只有同仁要填的欄位、選單直接是選項），按「加入」寫成原生表格的一列。原生表格仍可直接編輯，兩種方式並存，風險低。
3. **階段 2（大）**：整個明細改成卡片清單（每列一張卡：日期／交通工具／起訖點／金額在第一行，其餘收合），原生表格在新增／編輯頁對同仁收合。要先確認：
   - `set()` 寫回時游標、輸入法（注音選字中）會不會被打斷 → 卡片自己保留輸入，失焦（blur）才寫回。
   - 子表格的 `id`（列 ID）在 `set()` 後是否保持 → 用來對應卡片與列。
   - 帳號權限設定模組鎖的欄位，卡片要同樣唯讀。

## 2. 以同仁好填為方向的改善點

依「省掉打字 → 少選錯 → 錯了馬上知道」排序：

| # | 改善 | 說明 | 工作量 |
|---|---|---|---|
| 1 | **費用歸屬只列部內代碼** | 掛帳單位已限部內（§2.11），改成下拉／選單只列費用所屬人部門的代碼與中文名稱，預設帶部門最常用的一個；排除群組的人才列全部 | 中 |
| 2 | **複製上一列** | 每列一顆「複製」，帶出交通工具、起訖點、費用歸屬、拜訪客戶，日期改當天；來回程只改起訖點 | 小 |
| 3 | **常用行程** | 查自己最近 N 張單的「交通工具＋起訖點＋金額」組合，排成常用清單一鍵帶入 | 中 |
| 4 | **合計列** | 子表格沒有總金額欄：表格下方固定顯示筆數、金額合計、稅額合計，同仁送出前就能對帳 | 小 |
| 5 | **即時提示，不等存檔** | 發票號碼失焦就查「發票號碼記錄」有沒有重複、檢查格式（兩碼英文＋8 碼數字）；費用歸屬填部外代碼當下就標紅 | 中 |
| 6 | **依交通工具調整畫面** | 選計程車時理由欄自動展開、游標跳過去；選高鐵時憑證種類預設「高鐵票」 | 小 |
| 7 | **日期預設** | 新增列預設憑證日期＝上一列日期（第一列＝今天）；超過 N 天提醒「是否逾期請款」 | 小 |
| 8 | **說明文字收合** | 頁面上方的付款方式、付款原則說明改成可收合的提示框，表單往上縮 | 小 |
| 9 | **草稿暫存** | 每次變更把未存檔內容存 localStorage，不小心關頁可還原（只存本機、不跨裝置） | 中 |

## 3. 建議順序

1. 階段 0（隱藏會計欄）＋ #2 複製上一列 ＋ #4 合計列 ＋ #6、#7 ——都小，一次上線，立刻感受得到。
2. #1 費用歸屬只列部內代碼（要先確認費用歸屬主檔 `所屬部門` 已補齊）＋ #5 即時提示。
3. 階段 1「新增明細」視窗 → 收集使用回饋，再決定要不要做到階段 2 全卡片化。
