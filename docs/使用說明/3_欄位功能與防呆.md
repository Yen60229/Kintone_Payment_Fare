# 交通費請款單｜欄位功能與防呆

> 對象：填單同仁、會計。說明填寫時系統自動幫忙的地方，以及按「儲存」時會擋下的情況。
> 適用：交通費請款單（測試區 App 749），2026-10-28 版。
> 新增時的預設值見《1_新增表單的預設內容》，簽核見《2_簽核流程》。

---

## 一、交通費明細（子表格）

### 1. 交通工具決定能選哪些憑證種類

| 交通工具 | 可選的憑證種類 |
|---|---|
| 高鐵 | 高鐵票（**自動帶入**） |
| 火車、捷運／公車 | 車票（高鐵外）、收據、無 |
| 計程車 | 發票、收據、無 |
| Uber、停車費、汽機車短租 | 發票、收據 |

- 電腦版的「憑證種類」下拉選單**只會列出可選的項目**。
- 改了交通工具，原本選的憑證種類不能用時會**自動清空**，請重新選。
- 存檔時仍會再檢查一次，組合不對會列出「第 N 行…可選：…」。

### 2. 高鐵自動帶入賣方統編與格式

- 交通工具選「高鐵」→ 「賣方統編」自動填 `00000000`、「格式」自動填 `22`，兩欄鎖住。
- 改回其他交通工具 → 這兩欄自動清空、可以自己填。

### 3. 稅額自動計算

- 憑證種類是 **高鐵票** 或 **發票** → 「稅額」自動算：**金額（含稅）÷ 1.05 × 0.05，四捨五入到元**。
- 例：金額 1,490 元 → 稅額 71 元。
- 其他憑證種類（車票、收據、無，或還沒選）→ 稅額一律 **0**。
- **只重算你改的那一列**：改某一列的金額、憑證種類或交通工具，或新增一列時，才重算那一列的稅額。
- 開畫面、按儲存、改別的列，都**不會**動到已經填好的稅額。
- 會計單位可以手改稅額（依帳號權限設定）；手改後只要不再改那一列的金額、憑證種類或交通工具，就會保留。

### 4. 發票號碼／票號

- 憑證種類是 **高鐵票** 或 **發票** → 「發票號碼／票號」才能填，而且**必填**。
- 其他憑證種類 → 這欄自動清空並鎖住。
- **同一張單裡不能重複**：重複會列出號碼與第幾行。
- **不能和其他請款單重複**：已在其他單用過（作廢的單不算），存檔時列出號碼與對方的「交通費請款單號」。

### 5. 計程車

明細裡只要有一列是「計程車」：
- 「是否有紙本憑證」自動改成「**是**」，存檔時也必須是「是」。
- 「理由（計程車）」變成**必填**，標籤會出現紅色 *。

### 6. 費用歸屬

- 輸入後自動轉成**大寫**。
- 電腦版會在欄位下方顯示**中文名稱**（綠字）；代碼不存在時顯示「⚠ 代碼 "XXX" 不存在」（紅字）。
- 存檔時檢查：
  - 每一行都要填。
  - 代碼必須是費用歸屬主檔裡「使用中」的代碼。
  - **只能掛費用所屬人部內的代碼**：代碼的所屬部門要和費用所屬人部門屬於同一個部；不符會列出第幾行、哪個代碼、屬於哪個部門。
  - **一張單不能跨部門**：所有明細的費用歸屬要屬於同一個部。
  - 共用代碼（同一代碼分屬好幾個部，例如總公司代碼）只要其中一個部符合就算部內。
- 「費用歸屬不限部門」群組的同仁不受部內／跨部門限制。

### 7. 申請人與費用所屬人要同部門

- 存檔時檢查：「申請部門」和「費用所屬人部門」要屬於**同一個部**（同一個部底下的不同課也可以）。
- 不同部 → 擋下，列出兩邊的單位和各自屬於哪個部，請改選同部門的費用所屬人。
- 「費用歸屬不限部門」群組的同仁不受這個限制。

## 二、主表欄位

| 欄位 | 功能 / 防呆 |
|---|---|
| 申請人、受款人 | 只有系統管理員能改 |
| 申請部門、費用所屬人部門 | 一律鎖住，只能跟著人員帶入（多個單位時跳視窗選） |
| 費用所屬人 | 可改；改了會重帶部門、重排簽核人員、重算公司名稱與會計單位 |
| 公司名稱 | 依費用所屬人部門自動判斷（聯海通運的單位 → 聯海通運，其餘 → ＮＸ臺灣國際物流），鎖住 |
| 受款人 | 新增時空白會自動填申請人「員工代碼 中文姓名」；「同申請人」按鈕可一鍵重填（沒有申請人時會提醒「請先填寫申請人」） |
| 付款方式 | 存檔時**必須選、而且只能選一種** |
| 請款日期 | 鎖住 |
| 預計付款日 | 鎖住，存檔時自動計算（見下方） |
| 會計單位承辦人、權限開放人員 | 自動帶入，只有系統管理員看得到 |

### 預計付款日怎麼算

員工代墊款項支付日期為**每月 10 日、20 日、月底，遇假日順延**。

1. 從請款日期**隔天**起算，數 **5 個工作日**（會計作業時間）。
2. 取這天當天或之後的第一個付款日（10 日／20 日／月底）。
3. 付款日遇假日，往後順延到上班日。

> 例：請款日期 2026-10-28（三）→ 第 5 個工作日是 11/4（三）→ 之後第一個付款日 **11/10**。
> 工作日依公司行事曆（含國定假日與補班日）；行事曆讀不到時只排除週六日。

## 三、按「儲存」時

1. 畫面出現 **「儲存中，請稍候…」**，系統正在檢查，請不要重複按。
2. 有問題時跳出 **「表單驗證失敗」** 視窗：
   - 每個問題一張卡片、有編號；「第 N 行」標出明細行數、「」標出欄位、黃底紅字是重點。
   - 底部「提示」告訴你怎麼改。
   - 按「我知道了」回到表單修改，改好再按一次儲存。
3. 會一起檢查的項目：

| 檢查 | 錯誤訊息重點 |
|---|---|
| 必填欄位（依帳號權限設定） | 點名畫面上的欄位名稱；明細欄位附第幾列 |
| 公司名稱、付款方式 | 需填寫公司名稱／需選擇一種付款方式／限選一種付款方式 |
| 費用歸屬 | 第 N 行請確實填寫費用歸屬／不屬於最新分攤表 |
| 掛帳單位 | 只能是費用所屬人的部內／不能跨部門 |
| 申請人與費用所屬人 | 必須同部門 |
| 費用所屬人是部長 | 無法帶入「單位部長_支店長」（查不到部長群組時） |
| 交通工具與憑證種類 | 第 N 行…不能選「…」，可選：… |
| 發票號碼 | 請填寫／本單重複／已在其他單據出現 |
| 計程車 | 是否有紙本憑證必須選「是」／請填寫理由 |
| 手動簽核流程 | 人數與實際填寫不一致／請填寫單位部長/支店長、會計單位承辦人 |

> 勾了「表單作廢」的單，存檔時不做上述檢查（帳號權限設定的必填除外）。

## 四、列表畫面

- **列表直接編輯**：只能改「申請單號（Application Number）」「過帳日期（Posting Date）」「表單作廢」三欄（能不能改依帳號權限設定），其他欄位一律鎖住，要改請進編輯畫面。
- 列表直接編輯存檔時，也會檢查這幾欄的必填。
- 電腦版列表頁另有：批次下載附件、批次列印 PDF、SAP 轉檔（會計使用）。

---

## 五、依角色控制的欄位（帳號權限設定）

傳票編號、過帳日期等會計欄位，哪些人在哪一關看得到、能不能改、是否必填，由「帳號權限設定」App 統一設定（只在電腦版生效）。
系統自動帶入的欄位（部門、簽核人員、會計單位…）不受這裡影響，一律由系統鎖住。

---

## 六、其他

- **作廢確認**：按「作廢」時要輸入「作廢」兩個字才會執行（詳見《2_簽核流程》第七節）。
- **列印**：列印畫面會隱藏內部簽核與除錯用的欄位，明細表格依內容自動調整欄寬、沒有資料的欄位不印。
- **手機版沒有的功能**：帳號權限設定、列表批次下載／PDF／SAP 轉檔、列印頁、附件預覽、費用歸屬中文名稱提示、欄寬調整。其他填寫規則與存檔檢查手機版都有（手機的憑證種類選單會列出全部選項，選錯時會自動清空或在存檔時擋下）。
