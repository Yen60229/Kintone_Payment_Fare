# 交通費請款單｜新增表單時會自動帶入什麼

> 對象：填單同仁。說明按下「新增」打開表單時，系統幫你先填好、或先鎖住的欄位。
> 適用：交通費請款單（測試區 App 749），2026-10-28 版。

---

## 一、打開新增畫面時，系統依序做的事

1. **帶入你自己**：「申請人」「費用所屬人」都先填登入的人，「請款日期」填今天。
2. **帶入部門**：依申請人帶「申請部門」、依費用所屬人帶「費用所屬人部門」。
   - 只有一個所屬單位 → 直接帶入。
   - 有兩個以上 → 跳出視窗「○○ 有多個所屬單位，請選擇…部門」，**點一下要用的單位**就帶入。
   - 申請人和費用所屬人都要選的時候，兩個視窗會**一個接一個**出現，不會疊在一起。
3. **排簽核人員、帶會計單位**：依「費用所屬人部門」自動排好主管、次長、部長與會計單位（詳見《2_簽核流程》）。
4. **帶公司名稱**：依費用所屬人部門判斷是「ＮＸ臺灣國際物流」或「聯海通運」。
5. **帶受款人**：受款人空白時，自動填「員工代碼 中文姓名」（申請人本人）。
6. **畫面說明文字**：付款方式、付款原則、計程車要寫理由、受款人格式、預計付款日說明。

> 部門、簽核人員要向系統查資料，打開畫面後**約 1～2 秒**才會出現，請稍等再填。

## 二、每個欄位的預設值與能不能改

### 基本資料

| 欄位 | 打開時的預設 | 能不能改 |
|---|---|---|
| 請款日期 | 今天 | 🔒 不能改 |
| 申請人 | 登入的人 | 🔒 只有系統管理員能改（代填用） |
| 申請部門 | 申請人的所屬單位（多個時跳視窗選） | 🔒 不能手改，只能跟著申請人帶 |
| 費用所屬人 | 登入的人 | ✏️ 可以改，改了會重新帶部門與簽核人員 |
| 費用所屬人部門 | 費用所屬人的所屬單位（多個時跳視窗選） | 🔒 不能手改，只能跟著費用所屬人帶 |
| 公司名稱 | 依費用所屬人部門自動判斷 | 🔒 不能改 |
| 受款人 | 申請人的「員工代碼 中文姓名」 | 🔒 只有系統管理員能改；旁邊有「同申請人」按鈕可一鍵重填 |
| 付款方式 | 空白 | ✏️ **必須選一種**（只能選一種） |
| 是否有紙本憑證 | 是 | ✏️ 可改；明細有計程車時會強制為「是」 |
| 理由（計程車） | 空白 | ✏️ 明細有計程車時變成**必填**（標籤出現紅色 *） |
| 發票/憑證（附件） | 空白 | ✏️ **必填**，請上傳發票或憑證 |
| 預計付款日 | 空白 | 🔒 不能改，**按儲存時自動算** |

### 交通費明細（子表格）

打開時是空白的一列，以下欄位必填：憑證日期、交通工具、憑證種類、起訖點、拜訪客戶（目的）、金額（含稅）、費用歸屬。
其餘欄位會依你選的交通工具、憑證種類自動帶入或鎖住，規則見《3_欄位功能與防呆》。

### 簽核流程（預設收合的區塊）

| 欄位 | 打開時的預設 |
|---|---|
| 單位主管1～3、單位次長、單位次長1、單位部長/支店長 | 依費用所屬人部門自動排好，🔒 鎖住；沒排到人的格子會藏起來 |
| 單位主管簽核人數、單位次長簽核人數 | 依排到的人數自動填，🔒 鎖住 |
| 會計單位 | 依費用所屬人部門自動帶，🔒 鎖住 |
| 會計單位承辦人、權限開放人員 | 自動帶，只有系統管理員看得到 |
| 手動設定簽核流程 | 不勾（「費用歸屬不限部門」群組的同仁會**自動勾上**，簽核人員自己選） |

## 三、常見情況

**Q：我只有一個部門，為什麼沒有跳視窗？**
只有一個所屬單位時直接帶入，不用選。

**Q：選部門的視窗為什麼沒有「取消」？**
目前欄位上的部門不是這個人的單位（例如剛換人、或複製別人的單），一定要選一個才能繼續。原本的部門也是他的單位時，才會出現「取消（保留原本的部門）」。

**Q：我複製了同事的舊單，部門會不會錯？**
不會。打開時系統會檢查：部門不是你（申請人／費用所屬人）的單位，就重新帶入，簽核人員也跟著重排。
⚠️ 但**受款人已有值時不會覆蓋**，複製別人的單請確認受款人，或按「同申請人」重填。

**Q：我幫別人報（費用是別人的）？**
把「費用所屬人」改成那位同仁，系統會帶他的部門、依他的部門重排簽核人員與會計單位。

**Q：跳出「此費用所屬人沒有所屬單位」？**
這個人在 kintone 沒有設定組織，請改選其他人，或請管理員設定他的所屬組織。

**Q：部門或簽核人員一直沒出現？**
可能是網路或權限問題。重新整理頁面再試一次；仍然不行請聯絡系統管理員。

## 四、手機版

新增時的自動帶入（申請人、部門、簽核人員、會計單位、公司名稱、受款人、預計付款日）手機版都有。
手機版沒有「依角色調整欄位顯示／必填」的設定，傳票編號等會計欄位請用電腦處理。
