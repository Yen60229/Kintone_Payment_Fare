# 交通費請款單｜簽核流程

> 對象：填單同仁、簽核主管、會計。說明單子會經過誰、怎麼送、退回與作廢怎麼處理。
> 適用：交通費請款單（測試區 App 749），流程設定 rev 1821，2026-10-28 版。

---

## 一、整體順序

```
存檔 ──(系統自動)──▶ 草稿（未送出）
                        │ 申請人按「提交…」
                        ▼
        單位主管1 → 單位主管2 → 單位主管3      （有排到才會經過）
                        ▼
              單位次長 → 單位次長1             （有排到才會經過）
                        ▼
                  單位部長／支店長
                        ▼
        單位會計處理中（依會計單位分到 6 個會計群組）
                        │ 會計按「入帳完成」
                        ▼
                    請款流程結束
```

- **從哪一關開始，依費用所屬人的職位決定**：一般同仁從主管開始；費用所屬人是主管就從次長開始；是次長就從部長開始；是部長就直接到會計。
- 沒排到人的關卡會自動跳過，送出按鈕只會出現「下一個有人的關卡」。

---

## 二、存檔後的第一步：草稿（未送出）

1. 填好按「儲存」，系統會**自動**幫你按一次「點擊流程開始」，單子直接停在 **「草稿（未送出）」**。
2. 這時單子在**申請人**手上，還沒送給主管。確認內容無誤後，在詳細頁按上方的流程按鈕（例如「提交單位主管3確認」）才算送出。
3. 若存檔後畫面出現「流程處理中…」，是系統在補做第一步，稍等頁面重新整理即可。
   若出現「此單仍停在『報銷人填單』，請手動執行『點擊流程開始』」，請自己按一次該按鈕。

> 管理員代填時，「草稿（未送出）」會到**申請人**手上，由申請人自己送出。

---

## 三、簽核人員怎麼排出來的

系統依 **費用所屬人部門** 去「簽核流程主檔」找該單位的主管名單，再依以下規則整理：

| 規則 | 說明 |
|---|---|
| 主檔有填的人全部排上 | 單位主管1～3、單位次長、單位次長1、單位部長/支店長 |
| 不會自己簽自己 | 費用所屬人本人那一層與以下清掉。例：課長本人送單 → 不排課長，從次長開始 |
| 本人排在次長格 | 不論職稱都照次長處理，從部長開始簽 |
| 本人排在部長格 | 不論職稱都照部長處理，**直接送會計** |
| 同一人只簽一次 | 同一位主管同時排在主管3與次長1，只留上面那關（次長1） |
| 費用所屬人沒有職稱 | 主檔上的人全部排上 |
| 特定主管 | 台中營業部支店長、營業戰略部／總務部／事業本部部長送單時不排課／次／部長 |

人數欄位與關卡的對應：

| 單位主管簽核人數 | 會經過 | 單位次長簽核人數 | 會經過 |
|---|---|---|---|
| 0人 | （跳過主管） | 0人 | （跳過次長） |
| 1人 | 主管3 | 1人 | 次長1 |
| 2人 | 主管2 → 主管3 | 2人 | 次長 → 次長1 |
| 3人 | 主管1 → 主管2 → 主管3 | | |

**什麼時候會重排？** 新增時、改「費用所屬人」時（部門跟著重帶）。簽核欄位一律鎖住，不能手改。

---

## 四、手動設定簽核流程

適用：系統排的人不對、或特殊情況要自己指定簽核人。勾選「簽核流程」區塊裡的 **「手動設定簽核流程」**。

1. 勾選後，「簽核流程」區塊會展開，人數歸零、會計單位清空。
2. 選「單位主管簽核人數」「單位次長簽核人數」，對應的人員欄位才會出現，再填入人員。
3. **「單位部長/支店長」與「會計單位承辦人」必填**。
4. 存檔時檢查：選的人數要和實際填的人數一致，不一致會擋下並列出問題。
5. 手動流程送到最後是 **「單位會計處理中」**，由你指定的會計單位承辦人處理。
6. 取消勾選會跳確認「切換回自動模式會清除已填寫的內容」，按「確定」改回系統自動排人。

> 「費用歸屬不限部門」群組的同仁，新增時系統會**自動勾上**手動設定。
> 手動模式下改費用所屬人，系統不會蓋掉你自選的簽核人員。

---

## 五、各關卡能按的按鈕

| 目前狀態 | 誰處理 | 可以按 |
|---|---|---|
| 草稿（未送出） | 申請人 | 提交下一關、作廢 |
| 申請單位主管1／2／3確認中 | 該格主管 | 提交下一關、駁回、作廢 |
| 申請單位次長確認中 | 單位次長 | 提交次長1、駁回（**沒有作廢**） |
| 申請單位次長1確認中 | 單位次長1 | 提交下一關、駁回、作廢 |
| 申請單位部長確認中 | 單位部長/支店長 | 提交單位會計入帳、駁回、作廢 |
| 單位會計處理中（各地） | 該地會計群組 | 入帳完成、駁回、轉至其他會計、作廢 |
| 各種「駁回」 | 申請人 | 再申請（回到草稿）、作廢 |

### 會計關卡

- 系統依「會計單位」把單子分到：台北、台北海運、桃園&新竹、物流、台中、高雄；手動流程則到「單位會計處理中」（會計單位承辦人）。
- **送錯地方**：用「轉至○○會計」改送其他會計群組（六個會計之間都能互轉）。
- **入帳完成**：需先填「過帳日期（Posting Date）」，而且必須是**今年**的日期，按鈕才會出現。
- **退回修改**：台北會計有「返回至申請人」（回到草稿）、物流會計有「返回至單位主管」（回到主管3）；其他會計請用「駁回」。

---

## 六、駁回與再申請

1. 任一關按「駁回」→ 單子回到**申請人**，狀態顯示「○○駁回」。
2. 申請人進「編輯」修改後，按 **「再申請」** 回到「草稿（未送出）」，再重新送出。
3. 修改內容時，存檔檢查照常進行（見《3_欄位功能與防呆》）。

---

## 七、作廢

1. 先「編輯」→ 勾選 **「表單作廢(勾選完後簽核)」** → 儲存。（勾了作廢的單，存檔不會再做其他檢查）
2. 回詳細頁按 **「作廢」**。
3. 跳出確認視窗，顯示目前狀態、變更後狀態與記錄號碼，**輸入「作廢」兩個字**才能送出；按取消則不作廢。
4. 已作廢的單，詳細頁的「表單作廢」欄位會放大、加紅框提醒；作廢單用過的發票號碼可以在新單再使用。

---

## 八、注意事項（請管理員協助確認）

- **部長格的人必須在 kintone 群組「部長」裡**，否則流程會當作沒有部長：從草稿會直接送會計（跳過部長），從主管3／次長1 則會沒有送出按鈕。
- 費用所屬人部門在簽核流程主檔**找不到流程**時，不會排任何簽核人，送出會直接到會計。發現簽核人員是空的，請先聯絡管理員。
- 物流會計「返回至單位主管」退到主管3：若那張單沒有主管3（主管 0 人），退回後會**沒人能處理**，請改用「駁回」。
